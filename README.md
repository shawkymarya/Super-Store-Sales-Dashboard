# Super Store Sales Dashboard

An interactive Excel dashboard designed to analyze Super Store sales performance and provide a clear overview of key business metrics.

## Project Overview

This project transforms Super Store sales data into an interactive and easy-to-use Excel dashboard. The dashboard provides insights into sales performance across different time periods, regions, segments, states, and cities. It also includes interactive filters and a VBA macro to reset dashboard filters.

## Key KPIs

The dashboard includes the following key performance indicators:
- **Total Sales**
- **Total Profit**
- **Total Quantity**
- **Average Discount**

## Dashboard Analysis

The dashboard contains several visualizations:
- **Sales Over Time**: Trend analysis of sales.
- **Sales by Region**: Regional performance breakdown.
- **Sales by Segment**: Customer segment analysis.
- **Top 10 Sales by State**: Highest performing states.
- **Top 10 Sales by City**: Highest performing cities.

## Interactive Features

- Category filters
- Timeline filter for order dates
- Interactive PivotTables
- Dynamic dashboard updates
- VBA macro to clear/reset filters

## Tools & Technologies

- Microsoft Excel
- PivotTables & PivotCharts
- Excel Timeline
- VBA Macros
- Data Analysis & Dashboard Design

## Dataset

The dataset contains Super Store sales transactions with the following information:
- **Order Details**: Order ID, Order Date, Ship Date, Ship Mode
- **Customer Details**: Customer, Segment
- **Location**: Country, City, State, Region
- **Product Details**: Product, Category, Sub-Category
- **Financials**: Sales, Quantity, Discount, Profit

## How to Use

1. Download the Excel workbook (`Super_Store_Dashboard.xlsm`).
2. Open the file using Microsoft Excel.
3. **Enable macros** when prompted (this is required for the reset filter button to work).
4. Use the category filters and timeline to interact with the dashboard.
5. Click the **Reset Filters** button to return the dashboard to its default state.

## Dashboard Highlights

The dashboard was designed with a clean and simple layout to make important sales insights easy to understand at a glance. It combines KPI cards, trend analysis, regional analysis, segment analysis, and Top 10 rankings in a single-page dashboard.
