# Super Store Sales Dashboard

An interactive Excel dashboard designed to analyze Super Store sales performance and provide a clear overview of key business metrics.

## Project Overview

This project transforms Super Store sales data into an interactive and easy-to-use Excel dashboard.

The dashboard provides insights into sales performance across different time periods, regions, segments, states, and cities.

It also includes interactive filters and a VBA macro to reset dashboard filters.

## Key KPIs

The dashboard includes:

- Total Sales
- Total Profit
- Total Quantity
- Average Discount

## Dashboard Analysis

The dashboard contains several visualizations:

- Sales Over Time
- Sales by Region
- Sales by Segment
- Top 10 Sales by State
- Top 10 Sales by City

## Interactive Features

- Category filters
- Timeline filter for order dates
- Interactive PivotTables
- Dynamic dashboard updates
- VBA macro to clear/reset filters

## How to Use
Download the Excel workbook.
Open Super_Store_Dashboard.xlsm using Microsoft Excel.
Enable macros when prompted.
Use the category filters and timeline to interact with the dashboard.
Use the reset filters button to return the dashboard to its default state.


## Dashboard Highlights

The dashboard was designed with a clean and simple layout to make important sales insights easy to understand at a glance.

It combines KPI cards, trend analysis, regional analysis, segment analysis, and Top 10 rankings in a single-page dashboard.
